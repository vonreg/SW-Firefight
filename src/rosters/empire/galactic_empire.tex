{\large \textbf{Heir to the Empire Special Rules}}
\vspace{0.3cm}
\begin{multicols}{2}
    {\scriptsize

    \begin{minipage}{9cm}
        {\normalsize \textbf{Dark Magicks}}
        \vspace{0.3cm}

        The points cost of each friendly Night Trooper model is increased by 10 points, 
        and the points cost of each friendly Death Trooper model is increased by 25 points.

        \vspace{0.3cm}
        Each time a friendly Night Trooper model is eliminated, if that model did not have any upgrades,
        you may place a Night Trooper token within 1" of that model before removing them from play.
        Each time a friendly Death Trooper model is eliminated, you may place a 
        Death Trooper token within 1" of that model before removing them from play.
        Once per game, if this model has not been eliminated, you may replace
        each Night Trooper Token with a friendly Night Trooper model with the Zombie Night Trooper upgrade
        and each Death Trooper Token with a friendly Night Trooper model with the Zombie Death Trooper upgrade.
        These models must be placed within 1" of the token that they replace, and more than 1" from any enemy models.
        These models are now part of your squad.
    \end{minipage}

    }
\end{multicols}

{\Large \textbf{The Eternal Sanction}}
\vspace{0.3cm}

\begin{minipage}{19cm}
    The Eternal Sanction can be a subfaction of either the Galactic Empire faction, the
    Imperial Remnants faction, or the First Order faction. When building a squad,
    choose which of these factions the Eternal Sanction is a subfaction of, and follow
    the list restrictions and available profiles and options for that faction.
    \vspace{0.3cm}

    The Eternal Sanction includes profiles and options from the following roster, however
    some of these are restricted to one of the factions The Eternal Sanction can be drawn from
    as specified by the Faction[X] special rule.
    \vspace{0.3cm}

    If a squad is created from The Eternal Sanction as part of the Imperial Remnants faction,
    it may also take the Mandalorian Warrior and Mandalorian Commando profiles from the
    Mandalore Core List roster.
\end{minipage}
