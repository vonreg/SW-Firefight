{\Large \textbf{Imperial Remnant}}
\vspace{0.3cm}

\begin{minipage}{19cm}
    The Imperial Remnant faction includes all non-Unique profiles and options
    from the Galactic Empire roster with the exception of: Inquisitor; Imperial Royal Guard.
    It also includes all non-Unique profiles and options from the following roster except for Night Troopers.
    An Imperial Remnant squad may choose to be formed from one of the following forces,
    in which case it can include certain Unique and rare profiles and options from the following
    roster, listed in brackets.
    \begin{itemize}
        \item Gideon's Remnant (Moff Gideon)
        \item Thrawn's Return (Thrawn, Gilad Pellaeon, Enoch, The Great Mothers,
        Morgan Elsbeth, Marrok, Baylan Skoll, Shin Hati, Night Troopers)
        \item The Eternal Sanction (Rodjer Vonreg, Selina Kast)
    \end{itemize}
    Stormtroopers can take the Limited Supply upgrade for 0 points, and must take
    this upgrade if included in a squad not formed from Gideon's Remnant or Thrawn's Return.
    Additionally, Gideon's Remnant and The Eternal Sanction may also include the 
    Mandalorian Captain, Mandalorian Warrior and Mandalorian Commando profiles
    from the Mandalore Core List roster.
\end{minipage}

{\large \textbf{Faction Special Rules}}
\vspace{0.3cm}
\begin{multicols}{2}
    {\scriptsize

    \begin{minipage}{9cm}
        {\normalsize \textbf{Dark Magicks}}
        \vspace{0.3cm}

        The points cost of each friendly Night Trooper model is increased by 10 points, 
        and the points cost of each friendly Death Trooper model is increased by 25 points.

        \vspace{0.3cm}
        Each time a friendly Night Trooper model is eliminated, if that model did not have any upgrades,
        you may place a Night Trooper token within 1" of that model before removing them from play.
        Each time a friendly Death Trooper model is eliminated, you may place a 
        Death Trooper token within 1" of that model before removing them from play.
        Once per game, if this model has not been eliminated, you may replace
        each Night Trooper Token with a friendly Night Trooper model with the Zombie Night Trooper upgrade
        and each Death Trooper Token with a friendly Night Trooper model with the Zombie Death Trooper upgrade.
        These models must be placed within 1" of the token that they replace, and more than 1" from any enemy models.
        These models are now part of your squad.
    \end{minipage}

    }
\end{multicols}
